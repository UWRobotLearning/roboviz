Description

This is a visualization of all the translation data for this spiffy robotic arm.

Interactivity: Double-click on any demo name in the legend to isolate it, or double-click again to reset.

Explore translation data in detail using Entropy, KMeans, Kernel Density, and more!

Buttons: See the robot arm's state data along with all its metadata for a deeper dive into how it's moving. Watch the full video data or break it down by video segment to zoom in on specific movements. Explore clustering to understand how the whole trajectory is grouped, or focus on just parts of it.
